# Employee Attrition Analysis & Prediction

## 📌 Overview
A machine learning project that analyzes and predicts employee attrition using the IBM HR Analytics Employee Attrition dataset from Kaggle. The project includes an interactive Streamlit dashboard and SHAP-based explainable AI to identify key factors influencing employee turnover.

## 🚀 Features
- Exploratory Data Analysis (EDA) and interactive visualizations
- Employee attrition prediction using machine learning
- Model comparison and performance evaluation
- SHAP explainability for understanding feature importance and individual predictions
- Interactive Streamlit dashboard with HR insights

## 🛠️ Technologies Used
Python | Pandas | NumPy | Scikit-learn | Streamlit | Plotly | Matplotlib | Seaborn | SHAP

## 🤖 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## 📊 Model Evaluation
Models are evaluated using accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices.

## 📂 Dataset
**IBM HR Analytics Employee Attrition dataset — Kaggle**

The dataset contains employee demographics, job roles, income, job satisfaction, work experience, and attrition status.

## ⚙️ Installation & Usage

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project folder:
   ```bash
   cd employee-attrition-analysis
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   streamlit run app.py
   ```

## 🎯 Objective
To identify factors associated with employee turnover, predict attrition, and improve model transparency using SHAP explainability to support data-driven HR decisions.
